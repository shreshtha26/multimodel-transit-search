# multi-model-transit-search

multi-model-transit-search is a scalable multi-model exoplanet transit detection and benchmarking
pipeline. It builds forward from the existing single-target Kepler PDCSAP ARIMA
notebook into reusable ARIMA innovations, ARIMA-transformed-template matched
filtering, BLS/TCF/TPS-style comparisons, injection-recovery benchmarking,
feature-based ML, deep-learning morphology models, adaptive ensembles, and later
pixel-level validation.
